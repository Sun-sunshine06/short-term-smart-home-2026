# 软件组要求与当前首页范围

依据用户于 2026-11-17 提供的“数据访问软件（物联网+智科）”要求截图整理。

## 核心要求

1. 管理信息：存储和管理授权人员的信息。
2. 物体识别：从硬件模型中获取照片，使用 YOLO 识别物体，如人、车等不同类别。
3. 人脸识别开启门禁：至少实现“2 真 1 假”。该验收口径仍需向课程/小组确认，不自行等同于活体检测或两名授权人员。
4. GUI：Web 或手机界面，展示必要信息并支持统计分析，例如按特定时间间隔查询温度、灯光、门、窗的历史数据。

## 附加功能

5. 通过 GUI 远程控制灯、空调等开关。
6. 自行设计其他功能，例如摄像头检测到灯泡图片后控制灯亮。

## 本次 Astryx 首页

首页提供设备、雨滴/土壤，并突出视觉识别、门禁与授权人员、历史数据入口。设备、历史、视觉、门禁人员及系统页面已迁移到 Astryx 工作台。旧版保留为备用入口。首页提供 Astryx 与 shadcn/ui 两版对比，按用户要求移除了香橙派状态卡片。

演示模式的数据和开关只作用于浏览器内存，不发送真实样本或控制指令；演示不计作上述核心要求的实机验收。真实模式展示数据库与旁路状态，可保存人员及提交物体识别；执行控制与开锁尚未接入新版，未知/超时/未接入均不补造读数。

待后续实施/核验：完整历史库的起止时间查询（新版已支持最近 200 条的前端筛选与导出）；真实硬件照片到 YOLO 的闭环；真实人脸验证到门禁指令的闭环；“2 真 1 假”的准确口径；遥测与设备执行状态的来源和时效。当前新固件不回传旧板实际执行状态，不把命令入队当成执行成功。
