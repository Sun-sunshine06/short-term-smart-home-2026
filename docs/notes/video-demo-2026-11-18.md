# 2026-11-18 智能家居视频演示记录

演示已结束。当天使用的代码版本为 `405b9ae`，分支为 `feature/usb-camera-live-face-door`。电脑负责摄像头取帧、模型推理和控制指令下发。

| 功能 | 当天实测结果 |
| --- | --- |
| 环境采集 | 采集板在 COM3 以 115200 波特率握手成功，雨滴和土壤读数持续更新。重启后的一次抽查中，32 条记录全部投递，丢弃和错误均为 0。 |
| 手动控制 | 通过真实模式的 GUI 操作，现场确认灯、风扇均能开关，门能打开并自动关闭。电脑通过 COM3 下发指令，另一块 UNO 负责执行。 |
| 摄像头与物品识别 | ESP32-CAM 重接后使用 COM6，以 921600 波特率通过 USB 传输 640×480 JPEG。视觉识别页直接展示直播，可开启实时 YOLO。重接后的页面抽测中，画面与推理均显示约 10 FPS。 |
| 人脸门禁 | 门禁页使用同一路直播，自动抽帧比对已启用的授权人员。演示结束后核对本机记录，当天有 2 条实时人脸验证通过且开门指令已发往执行板的记录（`link_sent_no_ack`）。执行板没有门位回传，这两次自动开门的实物动作尚无单独的现场确认记录。 |
| 防重复开门 | 持续匹配同一人只下发一次指令；连续约 2 秒无人后可重新触发。自动测试覆盖持续在场、短暂漏检和离开后返回。 |
| 香橙派旁路 | 有线服务可达，认证成功。联调时板上时钟落后电脑约 19 小时 53 分，超出采样时间校验范围。收尾检查时，成功转发仍为 0，板端状态为 `never_received`。 |

发布前运行了 9 项后端测试、16 项项目测试和 7 项前端测试，全部通过；前端生产构建成功。
