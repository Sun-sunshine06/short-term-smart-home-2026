# 验证结果

双 UNO R3 USB_ASR_D3_V1 验证结果
日期：2026-11-17

本次实际完成：
1. 使用本机 Arduino AVR Boards 1.8.8 的实际核心和 avr-gcc 7.3.0 编译、链接两份源码，并生成 HEX。
2. 编译过程采用平台对应优化/LTO选项与 ATmega328P、16 MHz 配置；没有模拟编译器或用头文件替身编译固件。
3. 用 MSVC 19.42 / C++17 编译并运行包含实际两份 .ino、HomeLink.h、AsrD3Rx.h 的主机测试；测试编译无警告，全部断言通过。
4. 测试硬件接口使用 verification/stubs 的替身；单线程模拟不能证明实物采样时序可靠。

库版本：U8g2 2.36.19、DHT sensor library 1.4.7、Adafruit Unified Sensor 1.1.15、Adafruit NeoPixel 1.15.5、Servo 1.3.0。
旧板：Flash 21130 / 32256 字节（约 65.5%，扣除 Uno 引导区）；静态 SRAM 946 / 2048 字节，余 1102 字节供栈等使用。
新板：Flash 9126 / 32256 字节（约 28.3%）；静态 SRAM 1130 / 2048 字节，余 918 字节供栈等使用。
avr-size 原始输出以芯片完整 32768 字节计算 Flash 百分比，所以与上述可用应用空间比例略有不同。
应用代码及库编译无警告；核心仅有 new.cpp 的 unused parameter tag 警告。

已检查：
- V2 帧 CRC、全部命令、序号、重复帧、损坏位、丢边沿、启动中途、旧协议拒绝、计时回绕。
- D3 UART 全部 256 种字节、Timer1 比较值回绕、停止位错误、缓冲溢出、迟到采样、假起始位恢复。
- 键盘全部行、1234#、4 秒关门、错误密码报警期间仍执行命令、重复帧不延长开门。
- ASR 命令、USB PING/灯/风扇/自动模式、两路碎片输入隔离、USB 必须结束符、超时残片丢弃、ASR 错帧恢复。
- FACE_OPEN 冷却、不重复延长开门、冷却后可再次触发、有界队列拒绝过载。
- 触摸门铃且不自动开门、超声波回波与超时、雨水土壤上报和 15 秒过期、温控回差。

重要边界：
没有连接、烧录或测试现场实物。真实 ASR 电平、时钟误差、中断并发、供电、模块极性、机械动作和软件组 GUI 尚待联调。
模拟中的 343 ms 是给定替身环境下的第一份有效帧时延，不是实机响应指标。
本包没有增加状态返回线；QUEUED 和 SENT_NO_ACK 均不能证明旧板已执行成功。
旧板保留原 V2 运行逻辑；新板使用 D3/INT1 + Timer1 接收 ASR，USB 使用硬件串口 115200。

复现说明：
build_avr.py 为本机已安装核心与库缓存编译脚本，不安装依赖，不操作串口。
run_host_checks.cmd 使用本机 MSVC 路径；其他环境可以使用 C++17 编译器编译 verification/check_firmware.cpp，并将 verification/stubs 添加为头文件目录。
主机测试没有启用 ASan/UBSan，不继承原包使用 clang sanitizer 的验证结论。
