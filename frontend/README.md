# Astryx 智能家居工作台

新版入口 /next/，旧页面保留在 /。React 19 + Astryx，浅青色设计。
支持家庭概览、设备控制、历史数据、视觉识别、门禁与人员；系统页和组件对比版已移除。

## 开发与启动

需要 Node.js 22.18+（或 24 LTS）。在 frontend 目录运行 npm ci、npm run build，再启动后端，访问 http://127.0.0.1:5000/next/。
开发时运行 npm run dev，API 转发到本机 5000。运行构建后的页面无需单独 Node 服务。
构建产物不提交 Git，更新后需要重新构建。完整步骤见 [迁移说明](../docs/MIGRATION.md)。

## 行为边界

- 默认真实模式，右上角“演练模式”使用示例数据，不发送真实控制、人员保存和识别请求。演练设备状态跨页共享；页面内名册和识别结果离开对应页后重置。
- 首页读取电脑 /api/history 最近 30 条记录中的 uno_usb_asr_d3_v1 遥测，检查质量、范围和 15 秒时效；不依赖香橙派在线。
- UNO 桥接 enabled、connected、ready 均为真且状态查询新鲜时才允许发指令。滑动开关表示指令目标，不代表实物状态。link_sent_no_ack 表示投递后执行未确认；queued 表示排队中；超时不自动重试。
- 历史图表支持温度/灯光、时间筛选、分页与 CSV。筛选仅作用于最近最多 200 条已加载记录，不是全库查询。
- 真实模式的人员保存和图片识别会写入后端。物体识别传入 face_verify: false；门禁页展示真实记录，不主动开锁。展示阈值不修改模型参数。
- 开场约 1.6 秒，可跳过或重播；切页、卡片、图表和识别请求有动效。风扇和灯光效果只跟随明确的演练状态；遵从系统减少动态效果偏好。

验证命令：npm test、npm run build。真实图片推理、人员写入、串口控制和实物执行仍需同学电脑联调。软件要求见 [需求清单](../docs/SOFTWARE_REQUIREMENTS.md)。
